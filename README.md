# 🛍️ Mini E-Commerce Website

A simple and user-friendly e-commerce website built using **HTML, CSS, and JavaScript**. This project demonstrates front-end web development skills through a shopping interface with product pages, cart navigation, and user authentication screens.

## 📌 Project Overview

The Mini E-Commerce Website is a front-end web development project designed to provide a basic online shopping experience. It includes multiple pages for browsing products, viewing product details, accessing the shopping cart, and navigating login and registration screens.

## ✨ Features

- 🏠 **Home Page** – Displays the shopping website interface and products.
- 🛒 **Shopping Cart** – Provides a dedicated page for cart-related functionality.
- 📦 **Product Page** – Presents product-related information.
- 🔐 **Login Page** – Provides a login interface.
- 📝 **Registration Page** – Provides a user registration interface.
- ✅ **Thank You Page** – Displays a post-action confirmation page.
- 🎨 **Clean UI** – Styled with CSS for an attractive shopping experience.
- ⚡ **JavaScript Interactivity** – Adds client-side behavior to the website.

## 🛠️ Technologies Used

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Visual Studio Code (recommended)

### Installation and Setup

1. Clone this repository:

 git clone https://github.com/kanchukommula-sravani/Mini-Ecommerce.git

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Navigate through the website to explore its pages and functionality.
